# 식당 POS V53 / 주문내역 고정 및 결제수단 기본값 설정

V53은 V52의 메뉴판 빈칸/수기입력 기능을 유지하면서 주문 화면 운영성을 보강한 버전입니다.

## 주요 반영
- 우측 주문내역/합계/결제영역 고정 보강
- 결제수단 기본값 설정 추가
  - 관리자가 선택한 기본값 사용
  - 마지막 사용 결제수단 자동 기억
- 수기 내역 입력/수정에도 결제수단 기본 기준 적용
- 화면/문서 버전 V53으로 통일

## 업로드 파일
index.html, owner-inbox.html, assets/, manifest.webmanifest, sw.js, vercel.json, README.md, CHANGELOG.md, 배포메모.md
