# 식당 POS V46 / POS V42 UI 보존형

V43~V45에서 단순 데모형으로 바뀐 문제를 되돌리기 위해, 주문/외상장부/판매통계/관리자 흐름을 POS V42 기준에 가깝게 다시 구성한 버전입니다.

## 포함 기능
- 주문 화면: 테이블 선택, 식당식사/포장, 메뉴 선택, 결제수단, 결제완료
- 외상장부
- 판매통계: 기본형/종합형/세부재료분석형/요일별 예시
- 수기 내역 입력/수정
- 관리자 설정
- 우리매장 쪽지함 비밀번호/토큰 설정
- owner-inbox.html: 사장님 핸드폰용 우리매장 쪽지함

## 배포 기준
정적 배포 파일입니다. Vercel 설정은 Framework Preset Other, Build Command 빈칸, Output Directory '.', Install Command 빈칸입니다.
