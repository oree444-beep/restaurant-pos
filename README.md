# 식당 POS V57

V57은 V56 기준에 다음 운영 수정사항을 반영한 버전입니다.

## 주요 반영
- 판매/통계/최근 결제/영수증 관련 초기화 범위 보강
- 판매통계에 `판매내역` 탭 추가
- 빈칸/줄바꿈 정렬 항목을 실제 메뉴 통계에서 제외
- `줄바꿈 추가` 기능 추가
- 주문내역/결제버튼이 화면 아래로 사라지지 않도록 우측 패널 보강
- 외상장부/판매통계 큰 버튼을 하단 고정에서 일반 영역으로 변경
- 테이블 합치기/나누기 보조 기능 추가
- 더치페이 계산기 추가
- 시스템 설정 숫자 입력칸에서 입력 중 빈칸 허용
- 영수증 POS 복귀 버튼 확대
