# 식당 POS V51 / V42 UI 보존 기준

V51은 V42 원본 UI 흐름을 유지하면서 V49에서 확인된 배치 문제를 보강한 운영 수정 버전입니다.

## 주요 반영
- 우리매장 쪽지함 버튼을 상단 관리자모드 근처의 작은 보조 버튼으로 정리
- 수기 내역 입력/수정 버튼을 하단 큰 바에서 보조 버튼 위치로 이동
- 수기입력 메뉴명을 현재 등록 메뉴 목록에서 선택할 수 있는 UI 보강
- 수기 입력 후 날짜/시간/테이블/결제수단 등 입력값을 유지해 연속 입력이 쉽도록 보강
- 관리자모드 업데이트 데이터 보존 상태를 한 줄 접힘 토글 형태로 압축

## 배포
정적 배포 기준입니다. Vercel에서는 Framework Preset을 Other로 두고 Output Directory를 `.`로 설정합니다.


## POS V51 메뉴 수정 보강
- 관리자모드의 현재 메뉴 영역을 `현재 메뉴 수정/삭제`로 명확히 표시했습니다.
- 등록된 메뉴의 메뉴명, 가격, 구분, 주방전송 여부, 품절 여부를 바로 수정할 수 있다는 안내를 추가했습니다.
- 메뉴 삭제 시 확인창을 추가해 실수 삭제를 줄였습니다.
- 과거 주문내역은 당시 기록으로 유지하고 새 주문부터 수정된 메뉴 정보가 적용된다는 안내를 추가했습니다.
