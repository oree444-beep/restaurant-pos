# 식당 POS V61

V61은 V60의 통합결제/더치페이/판매내역 화면을 태블릿 운영에 맞게 보강한 버전입니다.

## 주요 반영
1. 테이블 합치기/나누기/더치페이 버튼 크기 확대
2. 통합결제 요약을 주문내역 제목 아래 한 줄로 배치
3. 통합 테이블 재선택 버그 보강
4. 더치페이 남은금액 강조 및 사람별 입력 목록 내부 스크롤
5. 판매내역 화면에서 인기 메뉴 TOP, 판매 없는 메뉴, 시간대별 판매금액을 3열로 배치
6. 메뉴별 판매내역 카테고리별 총액 표시

공통쪽지함 고객용 연결은 공통쪽지함 고객 화면과 종합관리의 inboxId/token 자동 생성 구조를 먼저 정리한 뒤 연결하는 것이 안전합니다.
