# 식당 POS V48 / V42 UI 보존 + 운영 보강

V48은 V42 원본 UI/배치를 기준으로 유지하면서, V47에서 추가한 우리매장 쪽지함/수기입력 기능을 보존하고 운영 중 헷갈렸던 부분을 보강한 버전입니다.

## V48 반영
- 상단의 우리매장 쪽지함/관리자모드 흐름 유지
- 관리자모드 `업데이트 데이터 보존 상태` 안내 기본 접힘 처리
- 월 이용료 기본 표시를 신규 이벤트 80% 기준 2,000원으로 보정
- `관리자에게 카톡 남기기` 문구를 `관리자에게 쪽지 남기기`로 변경
- 외상장부 문자전송은 문자 API/발신번호 등록 전까지 준비중 안내
- 판매통계 `세부재료분석형` 옆 `메뉴별 재료 설정` 바로가기 보강
- 샘플/통계 리포트에서 `\n`이 문자로 보이지 않도록 실제 줄바꿈 처리 보강

## 배포
정적 배포 기준입니다. GitHub 루트에 파일을 올리고 Vercel은 Framework Preset Other, Output Directory `.`로 설정합니다.
