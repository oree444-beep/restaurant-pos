# 식당 POS V52 / V42 UI 보존 기준

V52는 V42 원본 UI 흐름을 유지하면서 메뉴판 정렬용 `빈칸 추가` 기능을 넣은 버전입니다.

## 주요 반영
- 관리자모드 메뉴추가 영역에 `빈칸 추가` 버튼 추가
- 빈칸은 메뉴판 정렬용 자리만 차지하고 주문 클릭/가격 표시/판매통계/외상장부/수기입력 메뉴 선택에서는 제외
- 빈칸은 관리자모드 현재 메뉴 수정/삭제 목록에서 위치 이동/삭제 가능
- 수기 내역 입력/수정에서 등록 메뉴 선택 시 빈칸은 목록에 표시되지 않음
- 수기 입력 반영 후 모달을 닫지 않고 날짜/시간/테이블/결제수단을 유지해 연속 입력 가능
- `새 입력으로 초기화` 버튼으로 사용자가 원할 때만 초기화

## 배포
정적 배포 기준입니다. Vercel에서는 Framework Preset을 Other로 두고 Output Directory를 `.`로 설정합니다.
