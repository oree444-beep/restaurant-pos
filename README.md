# 식당 POS V60

V60은 V59의 테이블 통합결제/더치페이 화면을 태블릿 운영에 맞게 다시 압축하고, 통합결제 금액 계산 누락 문제를 보강한 버전입니다.

## 주요 반영

1. 화면 버전 표시 V60 통일
- 브라우저 제목, 화면 텍스트, 문서 기준을 V60으로 정리했습니다.
- V58/V59 잔류 표시가 화면에 보이지 않도록 보강했습니다.

2. 통합결제 요약 압축
- `통합결제: 2·3·5 / 총 00,000원` 한 줄 요약으로 표시합니다.
- 요약을 클릭하면 테이블별 금액표가 펼쳐지고, 다시 클릭하면 접힙니다.
- 주문내역 패널의 세로 공간을 덜 차지하도록 정리했습니다.

3. 통합결제 금액 계산 보강
- 선택된 현재 테이블만 계산하지 않고 통합 그룹의 모든 테이블 주문내역을 합산합니다.
- 각 테이블 주문은 독립적으로 유지하고, 결제할 때만 통합 처리합니다.

4. 버튼 배치 압축
- `테이블 합치기/테이블 나누기`와 `더치페이` 버튼을 주문내역 제목 오른쪽에 작게 배치하는 기준으로 정리했습니다.
- 독립 테이블에서는 `테이블 합치기`, 통합 테이블에서는 `테이블 나누기`만 보이게 했습니다.

5. 더치페이 계산기 복구
- 화면 아래에 일반 HTML처럼 길게 나오지 않도록 중앙 모달/팝업 형태로 복구했습니다.
- 태블릿에서 보기 쉽도록 입력칸과 닫기 버튼을 크게 보이게 했습니다.
