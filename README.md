# 식당 POS V58

V58은 V57 기준에서 테이블 통합결제 동작을 실제 운영 방식에 맞게 보강한 버전입니다.

## 주요 반영
- 테이블 합치기 동작 기준 수정: 주문은 각 테이블별로 유지하고 결제할 때만 통합 계산
- 통합 테이블 중 어느 테이블을 눌러도 `통합결제: 2·3·5·6` 요약 표시
- 통합결제 완료 시 묶인 테이블 전체 주문을 한 번에 결제 처리 후 비움
- `테이블나누기`가 실제로 통합 그룹을 해제하도록 수정
- 통합 테이블 번호 표시를 2·3·5·6처럼 오름차순 정렬
- 관리자모드에 `테이블 번호 글자크기` 설정 추가
- V57의 판매내역/줄바꿈/더치페이/주방테스트/영수증 복귀 기능 유지
