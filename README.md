# 식당 POS V49 / V42 UI 보존 + V48 반영 확인 수정

V49는 V48 배포 후 화면 상단이 V47로 표시되고 수기입력 위치가 헷갈렸던 문제를 바로잡은 수정본입니다. 기준 UI는 계속 V42 원본 배치를 유지합니다.

## V49 반영
- 화면 상단 POS 버전 라벨을 V49로 통일
- HTML title / manifest / README / CHANGELOG / 배포메모 버전 V49 통일
- 기존 V47 문자열 잔류 제거
- 하단 수기입력 버튼명을 `수기 내역 입력/수정`으로 명확화
- 수기 입력 모달은 주문일/결제일/메뉴/수량/금액/결제수단/외상정보를 입력하고 판매통계·외상장부에 반영되는 기존 기능 유지
- V42 원본 UI 기준 유지
- 우리매장 쪽지함, 관리자에게 쪽지 남기기, 문자전송 준비중 안내, 데이터 보존 안내 접힘 기능 유지
