# 생태한마리 POS V65

V65는 V65 기준에서 관리자모드 POS 공유 버튼 정렬, 주문내역 헤더 깨짐 수정, 통합결제 요약 클릭 영역 개선, 통합 테이블 선택 표시 가독성 개선을 반영한 버전입니다.

## 주요 반영
- 관리자모드 `POS기 주소복사`, `POS QR보기` 버튼을 관리자모드 제목 높이에 맞춰 정렬
- 주문내역 제목이 세로로 깨지지 않도록 헤더 구조 보강
- `테이블 합치기/나누기`, `더치페이` 버튼을 우측에 안정 배치
- 통합결제 요약 박스 전체 클릭으로 상세 펼침/닫힘
- 통합된 테이블 중 현재 선택된 테이블 표시를 더 진하게 구분


## POS V65 추가 수정
- 관리자모드 POS 주소복사/POS QR보기 버튼을 제목 라인 높이에 정렬했습니다.
- 주문내역 제목 테이블 번호 누락/잘림과 주문목록 내부 스크롤 구조를 보강했습니다.
- 원본비율 유지모드가 모바일에서 PC 기준 폭을 유지하도록 보강했습니다.
