# 식당 POS V62

V62는 V61 기준에 관리자모드 상단 POS 공유 버튼, 더치페이 금액 계산 보정, 수기 내역 간편 입력 보조 UI를 추가한 버전입니다.

## 주요 반영
- 관리자모드 상단 `POS기 주소복사`, `POS QR보기` 버튼 추가
- 다른 태블릿/핸드폰에서 POS를 바로 열 수 있도록 현재 restaurantId 포함 주소 공유
- 더치페이 계산기 총액 계산 보정
- 수기 내역 입력/수정 모달에 `간편 입력` 버튼과 한 줄 입력표 보조 UI 추가
- 화면/문서 버전 V62 정리

## 배포
정적 배포 기준입니다. GitHub 루트에 파일을 업로드하고 Vercel은 Other / Output Directory `.` 로 배포합니다.
