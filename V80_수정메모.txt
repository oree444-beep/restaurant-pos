POS V80 수정메모

기준: V78 안정버전 기준. V79는 테이블 번호 클릭 오류가 있어 사용하지 않음.

1. 결제완료 버튼 표시/고정 보강
- 메뉴/주문 항목이 많아져도 오른쪽 주문내역 영역 안에서 결제완료 버튼을 찾을 수 있게 내부 스크롤 및 결제 버튼 sticky 처리.
- V79처럼 테이블 클릭 오류를 만들지 않도록 React DOM 구조 직접 변경은 최소화.

2. 수기 내역 입력 > 간편입력 개선
- 간편입력 모달을 가로형으로 더 넓게 보이도록 조정.
- 화면을 넘어갈 경우 간편입력 패널 내부 스크롤 허용.
- 선택 행을 상세입력에 적용 버튼은 한 줄로 보이도록 폭 보강.
- 행 추가 버튼 폭 과점유 완화.
- 간편입력에도 판매 장부에 바로 반영 버튼 추가.

3. 간편입력 결제수단 글씨 표시 수정
- select class pay가 기존 결제완료 버튼 CSS와 충돌해 글씨가 안 보이던 문제 보강.
- 기본 상태에서도 현금/카드/카드+현금/상품권/기타 글씨가 보이게 글자색/배경색 수정.

4. 간편입력 메뉴선택 가격 오류 수정
- 인기메뉴 판매횟수/통계값을 가격처럼 읽는 문제 방지.
- 상세입력 메뉴 선택의 실제 가격 옵션을 우선 사용.
- 예: 생태탕/황태탕/애호박 돼지찌개 10,000원, 제육볶음 15,000원처럼 실제 메뉴 가격 표시.

5. 기존 정상 기능 유지
- restaurantId=rest_000001 접속 정상화 유지.
- 테이블 합치기/더치페이 버튼 우측정렬 및 통합결제 요약줄 분리 유지.
